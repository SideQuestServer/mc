★ SERIENFINALE ★

Was ist paintutils?

Mit paintutils und der term API kannst du auf dem CC-Terminal zeichnen – Farben setzen, Rechtecke füllen, Text positionieren. Das ist die Grundlage für alle GUIs in CC: Tweaked.

PART C · TERM API

Die wichtigsten term-Befehle

  • term.clear() – ganzen Screen mit Hintergrundfarbe füllen
  • term.clearLine() – aktuelle Zeile löschen
  • term.setCursorPos(x, y) – Cursor positionieren
  • term.getSize() – Breite und Höhe zurückgeben
  • term.setTextColor(colors.X) – Textfarbe
  • term.setBackgroundColor(colors.X) – Hintergrundfarbe
  • term.write("text") – Text ohne Zeilenumbruch schreiben
[i]
term.getSize() gibt Breite und Höhe zurück. Standard-Computer: 51 × 19. Damit kannst du deine GUI immer zentriert zeichnen, egal wie groß der Screen ist.
PART D · GUI BAUEN
★ ABSCHLUSSPROGRAMM – Reaktor GUI Dashboard
-- Hilfsfunktionen
local function zentriert(y, text, fg, bg)
    local w = term.getSize()
    local x = math.floor((w - #text) / 2) + 1
    term.setCursorPos(x, y)
    term.setTextColor(fg)
    term.setBackgroundColor(bg)
    term.write(text)
end

local function zeichneGUI(temp, energie)
    term.setBackgroundColor(colors.black)
    term.clear()

    -- Titelleiste
    paintutils.drawFilledBox(1,1, 51,1, colors.yellow)
    zentriert(1, "REAKTOR DASHBOARD", colors.black, colors.yellow)

    -- Temperatur Panel
    paintutils.drawFilledBox(2,3, 24,9, colors.gray)
    zentriert(4, "TEMPERATUR", colors.white, colors.gray)

    local tFarbe = colors.lime
    if temp >= 1000 then tFarbe = colors.red
    elseif temp >= 800 then tFarbe = colors.orange end
    zentriert(6, temp .. " C", tFarbe, colors.gray)

    -- Energie Panel
    paintutils.drawFilledBox(27,3, 50,9, colors.gray)
    zentriert(4, "ENERGIE", colors.white, colors.gray)
    zentriert(6, energie .. "%", colors.lime, colors.gray)

    -- Fußzeile
    paintutils.drawFilledBox(1,19, 51,19, colors.gray)
    zentriert(19, "[Q] Beenden", colors.white, colors.gray)
end

-- Hauptprogramm
zeichneGUI(750, 92)

while true do
    local ev, key = os.pullEvent("key")
    if key == keys.q then
        term.setBackgroundColor(colors.black)
        term.setTextColor(colors.white)
        term.clear()
        term.setCursorPos(1,1)
        break
    end
end
