▶ Episode 03

Variablen kombinieren

Strings zusammenführen · Rechnen · Fertige Ausgaben bauen

Wo wir stehen

In Teil 2 hast du gelernt, wie man Text und Zahlen in Variablen speichert. Jetzt gehen wir einen Schritt weiter: Wir verbinden mehrere Variablen zu einer einzigen Ausgabe.

Strings verbinden mit ..

In Lua verbindest du zwei Strings mit dem .. Operator (zwei Punkte). Das nennt sich Konkatenation.

verketten.lua
local vorname = "Steve"
local nachname = "Minecraft"

print(vorname .. " " .. nachname)
CraftOS 1.9 — Computer #1
CraftOS> verketten
Steve Minecraft
CraftOS>
[i]
Das Leerzeichen " " ist selbst ein String – ohne ihn würde SteveMinecraft ausgegeben. Denk immer daran, Leerzeichen explizit hinzuzufügen!

Zahlen mit Text kombinieren

Wenn du eine Zahl mit einem String verbindest, wandelt Lua die Zahl automatisch in Text um – du musst nichts extra tun:

spieler.lua
local name   = "Alex"
local level  = 42
local punkte = 1337

print("Spieler: " .. name)
print("Level:   " .. level)
print("Punkte:  " .. punkte)
CraftOS 1.9 — Computer #1
CraftOS> spieler
Spieler: Alex
Level: 42
Punkte: 1337
CraftOS>

Mit Zahlen rechnen

Zahlen-Variablen lassen sich direkt verrechnen. Das Ergebnis kannst du in einer neuen Variable speichern oder direkt ausgeben:

OP
Bedeutung
Beispiel
+
Addition
a + b
-
Subtraktion
a - b
*
Multiplikation
a * b
/
Division
a / b
%
Modulo (Rest)
10 % 3 → 1
^
Potenz
2 ^ 8 → 256
rechner.lua
local a = 10
local b = 3

print("Summe:   " .. (a + b))
print("Produkt: " .. (a * b))
print("Rest:    " .. (a %  b))
CraftOS 1.9 — Computer #1
CraftOS> rechner
Summe: 13
Produkt: 30
Rest: 1
CraftOS>
[!]
Beim Verbinden von Rechenergebnis und Text brauchst du Klammern um die Rechnung: print("X: " .. (a + b)) — ohne Klammern kann Lua den .. falsch interpretieren.
★ ABSCHLUSSPROGRAMM – Alles kombiniert
-- Spieler-Statusanzeige
local name         = "Alex"
local level        = 7
local xp           = 850
local xp_pro_level = 1000
local xp_rest      = xp_pro_level - xp

print("=== Spieler-Status ===")
print("Name:      " .. name)
print("Level:     " .. level)
print("XP:        " .. xp .. " / " .. xp_pro_level)
print("Bis Level " .. (level + 1) .. ": noch " .. xp_rest .. " XP")
print("=====================")
CraftOS 1.9 — Computer #1
CraftOS> status
=== Spieler-Status ===
Name: Alex
Level: 7
XP: 850 / 1000
Bis Level 8: noch 150 XP
=====================
CraftOS>

✔ Das hast du gelernt

  • Strings mit .. verbinden (Konkatenation)
  • Leerzeichen als eigenen String " " einfügen
  • Zahlen und Text direkt kombinieren
  • Rechenoperatoren: + - * / % ^
  • Zwischenergebnisse in Variablen speichern und weiterverwenden
  • Klammern bei Rechenoperationen im .. Ausdruck
