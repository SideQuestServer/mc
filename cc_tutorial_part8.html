▶ Episode 08

rednet

Computer vernetzen · senden · empfangen · broadcast

Was ist rednet?

Mit rednet können CC-Computer über ein Wireless Modem miteinander kommunizieren – Nachrichten senden, empfangen, und an alle gleichzeitig broadcasten. Perfekt für ein verteiltes Reaktor-Netzwerk auf deinem Server.

Computer A
ID: 1
SENDER
──▶ rednet.send(2, msg)
Computer B
ID: 2
EMPFÄNGER
┄┄▶ broadcast
Computer C
ID: 3
ALLE

Was brauchst du?

  • Mindestens 2 Computer (oder Turtles)
  • Je ein Wireless Modem – an einer Seite des Computers platzieren
  • Beide Computer in Modem-Reichweite (Standard: 64 Blöcke, Ender Modem: unbegrenzt)
  • Eigene ID abfragen mit os.getComputerID()

Die wichtigsten Funktionen

FunktionParameterWas sie tut
rednet.open"side"Modem öffnen ("right", "top" ...)
rednet.close"side"Modem schließen
rednet.sendid, msg, proto?Nachricht an bestimmte ID senden
rednet.broadcastmsg, proto?An ALLE Computer senden
rednet.receiveproto?, timeout?Auf Nachricht warten → id, msg, proto
os.getComputerID–Eigene Computer-ID abfragen
PART A · SENDEN & EMPFANGEN
▶ sender.lua (Computer A)
rednet.open("right")

local ziel = 2
rednet.send(ziel, "Hallo B!")
print("Gesendet!")

rednet.close("right")
▶ empfaenger.lua (Computer B)
rednet.open("right")

local id, msg = rednet.receive()
print("Von: " .. id)
print("Msg: " .. msg)

rednet.close("right")
CraftOS — Computer B (ID: 2)
CraftOS> empfaenger
-- wartet auf Nachricht...

Msg: Hallo B!
CraftOS>
[i]
rednet.receive() blockiert das Programm bis eine Nachricht ankommt. Mit Timeout: rednet.receive(nil, 5) wartet maximal 5 Sekunden – danach gibt es nil zurück.
PART B · BROADCAST
▶ alarm_sender.lua
rednet.open("right")

rednet.broadcast(
    "ALARM: Überhitzung!"
)
print("Alarm gesendet!")

rednet.close("right")
▶ alarm_empfaenger.lua
rednet.open("right")
print("Warte auf Alarme...")

while true do
    local id, msg =
        rednet.receive()
    print("["..id.."] "..msg)
end
PART C · PROTOKOLLE

Nachrichten filtern mit Protokollen

Mit einem optionalen dritten Parameter versiehst du Nachrichten mit einem Protokoll-Label. Der Empfänger hört dann nur auf ein bestimmtes Protokoll – sinnvoll wenn mehrere Programme gleichzeitig funken.

protokoll.lua
rednet.open("right")

-- Mit Protokoll senden
rednet.broadcast("temp:950", "reaktor_status")
rednet.broadcast("ALARM!",   "reaktor_alarm")

-- Nur "reaktor_alarm" empfangen, max 5 Sek
local id, msg = rednet.receive("reaktor_alarm", 5)

if msg then
    print("Alarm von #" .. id .. ": " .. msg)
else
    print("Kein Alarm empfangen.")
end
PART D · MODEM AUTO-ERKENNUNG
[!]
Das Modem muss auf der richtigen Seite sein! Mit peripheral.find("modem") findest du es automatisch – das ist robuster als eine feste Seite hardcoden.
auto_modem.lua
local modem = peripheral.find("modem")

if not modem then
    print("Kein Modem gefunden!")
else
    rednet.open(peripheral.getName(modem))
    print("Online! Meine ID: " .. os.getComputerID())
end
★ ABSCHLUSSPROGRAMM – Reaktor Netzwerk-Monitor
-- Monitor-Computer: empfängt alle Reaktor-Daten
local modem = peripheral.find("modem")
rednet.open(peripheral.getName(modem))

print("=== Netzwerk-Monitor ===")
print("ID: " .. os.getComputerID())
print("Warte auf Reaktor-Daten...")

while true do
    local id, msg = rednet.receive("reaktor")
    print("Reaktor #" .. id .. ": " .. msg)
end

✔ Das hast du gelernt

  • rednet.open() – Wireless Modem aktivieren
  • rednet.send(id, msg) – gezielt an eine ID senden
  • rednet.broadcast(msg) – an alle gleichzeitig
  • rednet.receive(proto, timeout) – empfangen & filtern
  • Protokoll-Labels für getrennte Kommunikationskanäle
  • peripheral.find("modem") – Modem automatisch erkennen
  • os.getComputerID() – eigene ID abfragen
