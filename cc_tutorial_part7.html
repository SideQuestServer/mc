Events

os.pullEvent · Tastatur · Maus · Timer

Was sind Events?

In CC: Tweaked passieren ständig Dinge – Tasten werden gedrückt, Redstone-Signale ändern sich, Timer laufen ab. All das sind Events. Mit os.pullEvent() wartet dein Programm auf das nächste Event und reagiert darauf.

Syntax
local event, arg1, arg2 = os.pullEvent("eventName")
-- wartet NUR auf diesen Event-Typ
-- ohne Argument: wartet auf JEDEN Event

Die wichtigsten Events

EventRückgabewerteWann?
key keyCode, held Taste gedrückt
key_up keyCode Taste losgelassen
char character Zeichen eingegeben
mouse_click button, x, y Mausklick
mouse_scroll direction, x, y Mausrad
timer timerID os.startTimer() abgelaufen
redstone – Redstone-Signal geändert
terminate – Strg+T gedrückt
PART A · TASTATUR-EVENTS
tastatur.lua
print("Drücke eine Taste (Q = Beenden)...")

while true do
    local event, key = os.pullEvent("key")

    if key == keys.q then
        print("Beendet!")
        break
    else
        print("Taste: " .. keys.getName(key))
    end
end
CraftOS 1.9 — Computer #1
CraftOS> tastatur
Drücke eine Taste (Q = Beenden)...
Taste: w
Taste: space
Taste: enter
Beendet!
CraftOS>
[i]
keys.q, keys.enter, keys.space usw. sind vordefinierte Konstanten in CC: Tweaked. Mit keys.getName(keyCode) bekommst du den Namen als String zurück.
PART B · MAUS-EVENTS
maus.lua
print("Klicke irgendwo! (Rechtsklick = Ende)")

while true do
    local ev, btn, x, y = os.pullEvent("mouse_click")

    if btn == 2 then   -- 1=links, 2=rechts, 3=mitte
        print("Beendet!")
        break
    else
        print("Klick bei X=" .. x .. " Y=" .. y)
    end
end
CraftOS 1.9 — Computer #1
CraftOS> maus
Klicke irgendwo! (Rechtsklick = Ende)
Klick bei X=12 Y=5
Klick bei X=3 Y=9
Beendet!
CraftOS>
PART C · TIMER-EVENTS
timer.lua
print("Timer gestartet...")

local t = os.startTimer(3)  -- 3 Sekunden

while true do
    local ev, id = os.pullEvent("timer")

    if id == t then
        print("Timer abgelaufen!")
        break
    end
end
[i]
Du kannst mehrere Timer gleichzeitig laufen lassen. Jeder bekommt eine eigene ID – deshalb vergleichst du id == t, um sicherzustellen dass es dein Timer war.
★ ABSCHLUSSPROGRAMM – Reaktor Notfall-Panel
-- Notfall-Panel: wartet auf Tastendruck
local aktiv = true

print("=== Notfall-Panel ===")
print("[S] Status  [A] Alarm  [Q] Beenden")

while aktiv do
    local ev, key = os.pullEvent("key")

    if key == keys.s then
        print("[OK] Reaktor laeuft normal")
    elseif key == keys.a then
        print("[!!] ALARM AUSGELOEST")
    elseif key == keys.q then
        aktiv = false
        print("Panel beendet.")
    end
end

✔ Das hast du gelernt

  • os.pullEvent() – wartet auf Events, gibt Typ + Argumente zurück
  • key Event + keys.NAME Konstanten
  • mouse_click Event mit Button (1/2/3) und X/Y Position
  • os.startTimer() + timer Event
  • Events in einer while true Schleife verarbeiten
  • Boolean als Schleifenschalter nutzen
