if / else

Entscheidungen treffen – dein Programm denkt mit

Was ist if/else?

Mit if kannst du deinem Programm sagen: "Wenn diese Bedingung wahr ist, mach X – sonst mach Y." Das ist die Grundlage für jede Logik in Lua.

Syntax
if bedingung then
    -- wird ausgeführt wenn bedingung = true
else
    -- wird ausgeführt wenn bedingung = false
end
[i]
In Lua braucht jedes if ein end am Schluss – vergisst du es, gibt es einen Fehler. Der else-Block ist optional.

Bedingungen formulieren

Eine Bedingung ist meist ein Vergleich zwischen zwei Werten:

OP
Bedeutung
Beispiel → Ergebnis
==
Gleich
5 == 5 → true
~=
Ungleich
5 ~= 3 → true
<
Kleiner als
3 < 10 → true
>
Größer als
10 > 3 → true
<=
Kleiner oder gleich
5 <= 5 → true
>=
Größer oder gleich
7 >= 3 → true
[!]
= ist Zuweisung (local x = 5).
== ist Vergleich (if x == 5 then).
Das ist einer der häufigsten Anfängerfehler!

Einfaches if/else

Wir prüfen ob ein Spieler genug XP für ein Level-Up hat:

levelup.lua
local xp         = 850
local xp_needed  = 1000

if xp >= xp_needed then
    print("Level Up! Gratulation!")
else
    print("Noch nicht. Dir fehlen: " .. (xp_needed - xp) .. " XP")
end
CraftOS 1.9 — Computer #1
CraftOS> levelup
Noch nicht. Dir fehlen: 150 XP
CraftOS>

if ohne else

Der else-Block ist optional. Manchmal willst du nur auf eine Bedingung reagieren und sonst gar nichts tun:

warnung.lua
local energie = 15

if energie < 20 then
    print("[!] Energie niedrig: " .. energie .. "%")
end

print("System laeuft weiter...")
CraftOS 1.9 — Computer #1
CraftOS> warnung
[!] Energie niedrig: 15%

CraftOS>

✔ Das hast du gelernt

  • Aufbau von if / else / end
  • Vergleichsoperatoren: == ~= < > <= >=
  • Unterschied zwischen = (Zuweisung) und == (Vergleich)
  • else ist optional – end nie!
  • Mehrere unabhängige if-Blöcke nacheinander verwenden
