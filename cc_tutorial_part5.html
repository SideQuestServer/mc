Mehrere Fälle mit elseif

In Teil 4 hattest du nur zwei Möglichkeiten: wahr oder falsch. Mit elseif kannst du beliebig viele Fälle abdecken – Lua prüft sie der Reihe nach und führt den ersten passenden Block aus.

Syntax
if bedingung1 then
    -- Fall 1
elseif bedingung2 then
    -- Fall 2
elseif bedingung3 then
    -- Fall 3
else
    -- Kein Fall traf zu
end
reaktorstufe.lua
local temperatur = 750

if temperatur >= 1000 then
    print("[KRITISCH] Notabschaltung!")
elseif temperatur >= 800 then
    print("[WARNUNG]  Temperatur hoch!")
elseif temperatur >= 500 then
    print("[OK]       Normalbetrieb")
else
    print("[INFO]     Reaktor kalt")
end
CraftOS 1.9 — Computer #1
CraftOS> reaktorstufe
[OK] Normalbetrieb
CraftOS>
[i]
Lua prüft von oben nach unten und stoppt beim ersten passenden Block. Deshalb fängst du immer mit dem strengsten Fall an – hier >= 1000 vor >= 800.

and · or · not

Mit logischen Operatoren kannst du mehrere Bedingungen in einem if kombinieren:

and
Beide Bedingungen müssen true sein
a > 0 and b > 0
or
Mindestens eine muss true sein
a == 0 or b == 0
not
Kehrt den Wahrheitswert um
not (a == b)

Übersicht: and / or / not

ABA and BA or Bnot A
truetrue truetruefalse
truefalse falsetruefalse
falsetrue falsetruetrue
falsefalse falsefalsetrue
zugang.lua
local level     = 10
local hat_key  = true

-- and: beide Bedingungen müssen stimmen
if level >= 5 and hat_key then
    print("Zugang gewaehrt!")
else
    print("Zugang verweigert.")
end

-- or: eine Bedingung reicht
local ist_admin = false
local ist_op    = true

if ist_admin or ist_op then
    print("Erweiterte Rechte aktiv")
end

-- not: Umkehrung
local gesperrt = false

if not gesperrt then
    print("System ist erreichbar")
end
