Variablen

Daten speichern und in print() verwenden

Was ist eine Variable?

Eine Variable ist wie eine beschriftete Kiste – du legst einen Wert hinein und kannst ihn später über den Namen wieder abrufen. In Lua erstellst du eine Variable einfach mit local:

Syntax
local variablenname = Wert

Die wichtigsten Typen in Lua

Typ Beispiel Beschreibung
string "Hallo" Text, in Anführungszeichen
number 42  /  3.14 Ganze Zahlen oder Dezimalzahlen
boolean true  /  false Wahr oder Falsch
nil nil Kein Wert / nicht gesetzt

Hello World – mit Variable

Statt den Text direkt in print() zu schreiben, speichern wir ihn zuerst in einer Variable:

hello2.lua
-- Text in einer Variable speichern
local nachricht = "Hello, World!"

-- Variable ausgeben
print(nachricht)
CraftOS 1.9 — Computer #1
CraftOS> hello2
Hello, World!
CraftOS>
[i]
Das Ergebnis ist identisch zu Teil 1 – aber jetzt steckt der Text in einer Variable. Das macht den Code flexibler: du änderst den Text nur an einer Stelle, egal wie oft du ihn verwendest.

Variablen mit Zahlen

Zahlen brauchen keine Anführungszeichen. Du kannst mit ihnen auch direkt rechnen:

zahlen.lua
local alter   = 25
local punkte  = 1337
local version = 1.21

print(alter)
print(punkte)
print(version)
CraftOS 1.9 — Computer #1
CraftOS> zahlen
25
1337
1.21
CraftOS>
[!]
Schreib immer local vor deine Variablen! Ohne local wird die Variable global – das kann in größeren Programmen zu schwer findbaren Fehlern führen.

✔ Das hast du gelernt

  • Was eine Variable ist und wozu sie dient
  • Wie du mit local eine Variable erstellst
  • Den Unterschied zwischen strings (Text) und numbers (Zahlen)
  • Eine Variable direkt an print() übergeben
  • Warum local fast immer die richtige Wahl ist
