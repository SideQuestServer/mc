Booleans & Schleifen

true / false als Schalter · while · for · break

PART A · BOOLEANS

Boolean – der einfachste Datentyp

Ein Boolean kennt nur zwei Werte: true oder false. Du kennst ihn schon aus den if/else-Bedingungen – aber du kannst ihn auch direkt in Variablen speichern und als Schalter nutzen.

true
An · Ja · Wahr · 1
false
Aus · Nein · Falsch · 0
schalter.lua
-- Boolean direkt in Variable
local reaktor_an  = true
local alarm_aktiv = false

if reaktor_an then
    print("Reaktor: ONLINE")
else
    print("Reaktor: OFFLINE")
end

-- Boolean umschalten (toggle)
alarm_aktiv = not alarm_aktiv
print("Alarm: " .. tostring(alarm_aktiv))
CraftOS 1.9 — Computer #1
CraftOS> schalter
Reaktor: ONLINE
Alarm: true
CraftOS>
[i]
Willst du einen Boolean als Text ausgeben, brauchst du tostring() – sonst gibt Lua einen Fehler beim Versuch, ihn mit .. zu verbinden.
PART B · WHILE-SCHLEIFE

while – solange wiederholen

Eine while-Schleife läuft so lange, wie ihre Bedingung true ist. Das macht sie ideal für Schleifen, bei denen du die Anzahl der Durchläufe nicht vorher kennst – z.B. "warte bis der Reaktor kühl ist".

Syntax
while bedingung do
    -- wird wiederholt solange bedingung = true
end
countdown.lua
local i = 5

while i > 0 do
    print("Countdown: " .. i)
    i = i - 1
end

print("Start!")
CraftOS 1.9 — Computer #1
CraftOS> countdown
Countdown: 5
Countdown: 4
Countdown: 3
Countdown: 2
Countdown: 1
Start!
CraftOS>

while true – Die Endlosschleife

In CC: Tweaked ist while true do sehr häufig – sie lässt ein Programm dauerhaft laufen (z.B. ein Monitoring-Script). Mit break kannst du die Schleife jederzeit verlassen.

monitor.lua
local durchlauf = 0

while true do
    durchlauf = durchlauf + 1
    print("Check #" .. durchlauf)

    if durchlauf >= 3 then
        print("Fertig – Schleife beendet")
        break  -- verlässt die while-Schleife
    end
end
CraftOS 1.9 — Computer #1
CraftOS> monitor
Check #1
Check #2
Check #3
Fertig – Schleife beendet
CraftOS>
[!]
while true do ohne break läuft ewig! In CraftOS kannst du mit Strg+T ein laufendes Programm abbrechen.
PART C · FOR-SCHLEIFE

for – genau N-mal wiederholen

Die for-Schleife ist ideal wenn du genau weißt, wie oft etwas passieren soll. Sie zählt automatisch – du musst den Zähler nicht selbst erhöhen.

Syntax
for i = start, ende, schritt do
    -- schritt ist optional, Standard = 1
end
zählen.lua
-- Vorwärts zählen
for i = 1, 5 do
    print("Schritt " .. i)
end

-- Rückwärts zählen (Schritt = -1)
for i = 3, 1, -1 do
    print("Countdown: " .. i)
end

-- Nur gerade Zahlen (Schritt = 2)
for i = 2, 10, 2 do
    print(i)
end
CraftOS 1.9 — Computer #1
CraftOS> zählen
Schritt 1  / Schritt 2  / Schritt 3  / Schritt 4  / Schritt 5
Countdown: 3  / Countdown: 2  / Countdown: 1
2  4  6  8  10
CraftOS>
while – wenn?
Anzahl Durchläufe unbekannt.
Läuft bis Bedingung false.
z.B. "warte bis Reaktor kalt"
for – wenn?
Anzahl Durchläufe bekannt.
Zähler wird automatisch erhöht.
z.B. "5 Blöcke abbauen"
★ ABSCHLUSSPROGRAMM – Reaktor-Bootsequenz
-- Reaktor Bootsequenz mit Boolean + Schleifen
local bereit    = false
local temp      = 1200
local ziel_temp = 800

print("=== Bootsequenz gestartet ===")

-- while: warte bis Reaktor abgekühlt
print("Kuehlphase...")
while temp > ziel_temp do
    temp = temp - 200
    print("  Temp: " .. temp .. " C")
end

-- for: Selbsttest (3 Checks)
print("Selbsttest...")
for i = 1, 3 do
    print("  Check " .. i .. ": OK")
end

-- Boolean als Ergebnis setzen
bereit = true

if bereit then
    print("=== Reaktor ONLINE ===")
end
CraftOS 1.9 — Computer #1
CraftOS> boot
=== Bootsequenz gestartet ===
Kuehlphase...
Temp: 1000 C
Temp: 800 C
Selbsttest...
Check 1: OK
Check 2: OK
Check 3: OK
=== Reaktor ONLINE ===
CraftOS>
