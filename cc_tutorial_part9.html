Tabellen

Arrays · Key-Value · ipairs · pairs

Was ist eine Tabelle?

Eine Tabelle ist Lua's universeller Container – sie kann als Array (nummerierte Liste) oder als Dictionary (Schlüssel-Wert-Paare) verwendet werden. Alles in einem Typ.

PART A · ARRAY (LISTE)
INDEX
1
2
3
4
WERT
"Reaktor A"
"Reaktor B"
"Reaktor C"
"Reaktor D"
[i]
In Lua beginnen Arrays bei Index 1, nicht bei 0 wie in den meisten anderen Sprachen!
array.lua
local reaktoren = {"Reaktor A", "Reaktor B", "Reaktor C"}

-- Einzeln zugreifen
print(reaktoren[1])  -- Reaktor A
print(reaktoren[2])  -- Reaktor B

-- Länge mit #
print("Anzahl: " .. #reaktoren)

-- Eintrag hinzufügen
reaktoren[4] = "Reaktor D"
print("Jetzt: " .. #reaktoren)

-- Mit ipairs durchlaufen
for i, name in ipairs(reaktoren) do
    print(i .. ": " .. name)
end

keyvalue.lua
local reaktor = {
    name    = "Reaktor A",
    temp    = 750,
    online  = true,
    energie = 92
}

-- Zugriff mit Punkt oder eckiger Klammer
print(reaktor.name)
print(reaktor["temp"])

-- Wert ändern
reaktor.temp = 820

-- Mit pairs alle Einträge ausgeben
for key, val in pairs(reaktor) do
    print(key .. " = " .. tostring(val))
end

PART C · TABELLEN VERSCHACHTELN
nested.lua
-- Tabelle aus Tabellen (Liste von Reaktoren)
local reaktoren = {
    { name="Reaktor A", temp=650 },
    { name="Reaktor B", temp=920 },
    { name="Reaktor C", temp=1050 },
}

for i, r in ipairs(reaktoren) do
    local status = "OK"
    if r.temp >= 1000 then status = "KRITISCH"
    elseif r.temp >= 800 then status = "WARNUNG"
    end
    print(r.name .. ": " .. r.temp .. "C [" .. status .. "]")
end
CraftOS 1.9 — Computer #1
CraftOS> nested
Reaktor A: 650C [OK]
Reaktor B: 920C [WARNUNG]
Reaktor C: 1050C [KRITISCH]
CraftOS>
[!]
ipairs → für nummerierte Arrays (stoppt beim ersten nil).
pairs → für Key-Value Tabellen (geht alle Einträge durch, Reihenfolge nicht garantiert).
★ ABSCHLUSSPROGRAMM – Reaktor-Datenbank
local db = {
    { name="Reaktor A", temp=700, energie=95, online=true  },
    { name="Reaktor B", temp=850, energie=78, online=true  },
    { name="Reaktor C", temp=200, energie=0,  online=false },
}

print("=== Reaktor-Datenbank ===")
for _, r in ipairs(db) do
    if r.online then
        print(r.name .. " | " .. r.temp .. "C | " .. r.energie .. "%")
    else
        print(r.name .. " | OFFLINE")
    end
end

✔ Das hast du gelernt

  • Tabelle als Array – nummerierte Liste ab Index 1
  • #tabelle – Länge eines Arrays
  • Tabelle als Key-Value – Zugriff mit tabelle.key oder tabelle["key"]
  • ipairs() – Array der Reihe nach durchlaufen
  • pairs() – alle Key-Value Einträge durchlaufen
  • Tabellen verschachteln – Tabelle aus Tabellen
  • _ als Platzhalter wenn ein Rückgabewert nicht gebraucht wird
